# Nature's Aura — Ecosystem Magic Mod

[![Download Latest](https://img.shields.io/github/v/release/SoundEmancipate/natures-aura-magic-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/SoundEmancipate/natures-aura-magic-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Draw aura from the natural world to power rituals, grow unique plants, and enchant equipment.

## Features

- Aura system — harvest natural energy from the biome
- Altars and offerings for ritual-based crafting
- Unique plants that grow only with sufficient Aura
- Aura reader shows local Aura levels in the world
- Peaceful, exploration-focused magic progression

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
